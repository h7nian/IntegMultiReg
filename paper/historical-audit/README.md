# Historical KIRC audit — excluded from current manuscript evidence

This directory preserves the removed legacy raw-time KIRC manuscript section
and the 0.1.4 replication-script snapshot immediately before scope revision.
The table predates corrected log-time preprocessing and training-refit CV.
It is not a performance result for the current package and is no longer cited
by the submitted manuscript or generated by its current replication entry point.

The script snapshot is provenance, not a recipe guaranteed to reproduce the old
table: it already calls the newer package CV. The separate frozen 0.1.3 archive
is retained unchanged at paper/IntegMultiReg-replication. Historical scripts,
software versions and table values must not be mixed with current references.

A new full-scale KIRC performance study would require corrected log-time fitting,
training-only feature screening, training-refit (and nested, if tuned) validation,
and adequate chain diagnostics. Moving this table does not mean such a study
has been completed. The current manuscript makes no full-scale KIRC performance
claim and retains the reduced KIRC data only as a software-interface example.
